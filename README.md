# 🎯 IELTS 7.0 Learning Plan (Revised – Input 5.0, 8 Months)
----------------------------------------
This document provides a 32-week structured plan (~8 months) to help achieve an overall IELTS Band 7.0 from a starting level of Band 5.0.
The plan covers all four test components: Listening, Reading, Writing, and Speaking.

# 1. Overview
| Item            | Details                                                            |
| --------------- | ------------------------------------------------------------------ |
| Goal            | **Overall 7.0 (L/R: 7.0–7.5, W/S: 6.5–7.0)**                       |
| Timeframe       | **32 weeks (~8 months)** với ~2–3 hours/day                        |
| Target Audience | Learners ở mức **Band ~5.0**                                       |
| Strategy        | Ưu tiên **Writing + Speaking**, dùng Listening/Reading để kéo điểm |

# 3. Weekly Study Plan (32 weeks)
| Giai đoạn | Tuần       | Trọng tâm       | Nội dung chính                                                                                                           |
| --------- | ---------- | --------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Phase 1   | Week 1–6   | Foundation      | - Sửa grammar (câu, thì, lỗi cơ bản) <br> - Listening Section 1–2 <br> - Reading basic skills <br> - Writing: câu + đoạn |
| Phase 2   | Week 7–14  | Skill Building  | - Listening full sections <br> - Reading timed <br> - Writing Task 1 + Task 2 cơ bản <br> - Speaking Part 1–2            |
| Phase 3   | Week 15–24 | Band 6.5+       | - Full test từng phần <br> - Writing nâng cao (idea + coherence) <br> - Speaking Part 2–3                                |
| Phase 4   | Week 25–32 | Test & Optimize | - Full mock test <br> - Sửa lỗi sâu <br> - Tối ưu chiến lược thi                                                         |

🎯 Task cụ thể theo tuần

Week 1–2
Grammar: câu đơn, thì hiện tại/quá khứ
Listening: Cambridge Section 1
Writing: viết câu đúng

Week 3–4
Grammar: câu phức (because, although…)
Listening: Section 2
Writing: viết đoạn 80–100 từ

Week 5–6
Reading: True/False/Not Given
Writing: bắt đầu Task 1 (basic)
Speaking: trả lời dài hơn (2–3 câu)

Week 7–8
Listening: Section 3
Reading: Matching headings
Writing: Task 2 (intro + 1 body)
